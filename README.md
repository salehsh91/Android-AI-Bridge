# Android AI Bridge

Android AI Bridge is an open-source framework that automates AI websites directly from Android browsers.

Instead of using Playwright, it uses:
- Browser Extension
- WebSocket
- Node.js (Termux)

## Goals

- ChatGPT
- Gemini
- DeepSeek
- Claude
- Grok
- Copilot
- Qwen

## Features

- Send prompts
- Read responses
- Click buttons
- Fill inputs
- Wait for AI completion
- Multi-provider support
- Android-first architecture
